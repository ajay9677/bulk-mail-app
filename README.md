# 📧 Bulk Mail Application – MERN Stack

## 📌 Project Overview

The **Bulk Mail Application** is a full-stack web application developed using the MERN stack. It allows users to send emails to multiple recipients at once through a simple and user-friendly interface.

The application uses React for the frontend, Node.js and Express.js for the backend, MongoDB for storing email records, and Nodemailer for sending emails.

## 🎯 Objectives

- Build a responsive bulk email sending interface.
- Send emails to multiple recipients simultaneously.
- Integrate the React frontend with the Express backend.
- Store email records and delivery status in MongoDB.
- Handle validation, success messages, and error responses.

## 🚀 Features

- 📩 Enter email subject and message body.
- 👥 Add multiple recipient email addresses.
- ✉️ Send bulk emails using Nodemailer.
- ✅ Display success and failure messages.
- 🗄️ Store email records in MongoDB.
- 📜 Maintain email history for previously submitted emails.
- 📱 Responsive and user-friendly interface.

## 🔄 Application Workflow

1. The user enters the email subject and message.
2. The user provides multiple recipient email addresses.
3. The React frontend sends the form data to the backend API.
4. The Express server validates the request.
5. Nodemailer processes the email sending request.
6. MongoDB stores the email record and its sending status.
7. The frontend displays the appropriate success or failure message.

## 🔐 Security Considerations

- Store credentials in environment variables.
- Validate recipient email addresses.
- Never expose email passwords or database credentials.
- Avoid sending unsolicited emails.
- Use authorized recipient lists and follow email provider sending limits.
